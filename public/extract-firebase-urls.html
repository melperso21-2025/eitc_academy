🔗 Extraer URLs de Firebase Storage

Obtén automáticamente las URLs públicas de todas tus imágenes

1️⃣ Configuración de Firebase

Encuéntralo en: Firebase Console → Configuración del proyecto → ID del proyecto

2️⃣ Información de las Imágenes

Copia los nombres exactos desde Firebase Storage (incluye extensión)

3️⃣ Generar URLs

✅ URLs Generadas

⚠️ Próximo paso:

  1. Copia una URL del listado de abajo
  2. Ve a: http://localhost:8000/update-images.html
  3. Pega la URL, selecciona curso, y haz click "Actualizar"
  4. Repite para cada imagen

📍 ¿Cómo obtener Project ID?

  1. Ve a Firebase Console
  2. Selecciona tu proyecto "eitc-academy"
  3. Click en el icono de engranaje (⚙️) → Configuración del proyecto
  4. Copia el "ID del proyecto"
